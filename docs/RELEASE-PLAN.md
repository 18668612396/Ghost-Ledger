# 多平台发布计划与验收

更新：2026-10-26。用户目标：解决现有首幕的发布缺口，优先完成 Web 发布；微信小游戏实际发布暂缓，同时为 Windows 与 Android 预留独立打包架构。首发内容沿用第一幕「阴路夜巡」，不增加第二套规则引擎。

Web 已上线：[在线试玩](https://18668612396.github.io/Ghost-Ledger/)。目标仓库：[18668612396/Ghost-Ledger](https://github.com/18668612396/Ghost-Ledger)。正式回归现经用户允许纳入 `tests/`；临时测试、截图、日志、构建和历史归档继续放在被 Git 忽略的 `.local/`。

## 原问题的处理

| 原问题 | 本次实现 | 验收与边界 |
| --- | --- | --- |
| 运行素材原样复制、完整包约 355 MiB | 构建只发布 196 张运行图，按展示尺寸生成 WebP；来源 PNG、提示词、定位和透明边界保留。 | 图片 322.86 → 72.30 MiB，减少 77.61%；完整包约 73 MiB。原图哈希、派生尺寸、定位和两次构建一致性已检查。运行时不发布 21 张溯源原件及策划工具。 |
| 没有可重复的发布链路 | 锁文件、Node 24 的 Linux/Windows 验证、手动 main 分支 Pages 工作流；严格发布预检。 | `npm ci`、规则回归、三首领演练、失败恢复、构建与子路径检查均由 CI 执行。工作流上线结果在后文单独记录。 |
| 固定文件名易混用版本 | 入口指向 `releases/<releaseId>/`，同一版本的模块和带哈希图片绑定；更新只读取站点入口同级 `release.json`。 | 已打开的页面继续使用自己的版本；手动保存刷新才更新。发布时只保留上一个不同版本，预算为当前 80 MiB、总计 160 MiB。 |
| 上一次 Actions 制品过期会阻止后续发布 | 优先下载上次成功发布的制品；缺失或过期时，从 Pages API 指定的本站 HTTPS 地址恢复。 | 恢复只接收同源、同路径、无重定向的数据，逐文件校验大小和 SHA；失败停止发布，保留恢复现场。不会执行下载的脚本。 |
| 存档只存在于当前地址 | 增加进度备份下载、复制、文件/粘贴导入与替换确认；原始记录单独导出。 | 校验格式、规则快照、所需图片、局外档案和试玩记录；导入失败回滚，导入前原文留档。损坏记录可回退到上次有效副本。 |
| 更换格式可能丢失旧记录 | 唯一运行格式升级为 `version:5 / ruleset:config-v2`，使用 `ghost-ledger.run.v5`。 | 不运行或迁移旧规则；旧 `run.v4` 原文保留并提示。局外档案键仍为 `ghost-ledger.profile.v2`。 |
| 保存失败或旧标签页覆盖进度 | 丢弃/替换旧夜巡前必须成功保存档案；新局先成功落盘再切换。写前比较本页基线，订阅外页存储变动。 | 检测外部更新后，本页停止写入和游戏动作，仍可导出内存备份或重新加载。此检测处理已发生的外部写入；localStorage 不是原子数据库，不声称跨标签事务锁。 |
| 测试随 `.local/` 被忽略 | 正式回归及必要静态夹具纳入 `tests/regression/`、`tests/fixtures/`；完整冒险驱动放 `tests/scenarios/`。 | 干净克隆无需历史 `.local/` 即可执行；旧本地文件保留。所有新输出仍进入 `.local/`。 |
| 浏览器接口散落、后台恢复不统一 | `platform/contract.js` 约定存储、文件、音频、时钟、输入坐标与生命周期；Web/WebView 与微信分别适配。 | 失焦清拖牌与临时选敌，暂停音频、累计有效局时并保存；动画只播放事件，不在恢复或回调中重新结算。 |
| 加载失败时无处理 | 入口启动失败显示恢复页；卡图失败显示重试；运行错误保留可导出的原始记录。 | 恢复页是单向状态，普通焦点/缩放/异步动画不会把它覆盖。缺失素材不替换成不相符的通用图。 |
| 首次操作不清晰 | 首场战斗五步引导，可跳过和重开。 | 覆盖点怪看意图、点牌看详情、攻击上拖/自身下拖、箭头/泛白/变暗、香火、借火还愿与备份。战场常态仍不显示意图。 |
| 反馈不能复现 | 导出本地试玩摘要、种子、内容/构建版本、有效局时、动作序列、最后状态与失败原因；历史补充种子、局时和败因。 | 不自动联网收集反馈，不包括账号凭据；恢复的中途记录会标记不完整，动作最多保留 2000 条。 |
| 法器、药物写死 | 九张源表，新增 8 法器、4 药物；使用通用触发、效果与修正，工坊支持编辑及真实规则预览。 | 新局固定九表快照，继续旧的当前格式夜巡不混入新的道具数值。 |
| 导入的文本可能被当作网页执行 | 配置/快照文字与属性转义，构建入口加同源 CSP，禁止内联脚本和动态代码执行。 | 文本中的引号和比较符仍可正常显示；脚本限制作为额外防线，不能代替渲染转义。 |
| 首幕与手机证据不足 | 正常数值三首领胜利、被动失败、分段保存恢复和独立动作回放；浏览器复演与物理手机分层记录。 | 策略搜索能找出通关路线，不等于人类胜率、趣味性或实际 25–40 分钟局时。物理设备与用户试玩须另行验收。 |

## 平台边界

| 目标 | 共享部分与宿主 | 当前交付状态 |
| --- | --- | --- |
| Web | 当前 DOM 界面、规则、九表、资源清单、平台服务。 | 独立静态包，可部署 GitHub Pages 或其他静态 HTTPS 站点；配置工坊和 QA 文件不进入站点。 |
| Windows | Tauri 2 WebView 宿主复用 Web 界面；规则与素材仍同源。 | 可生成独立准备目录与应用图标；未安装/执行原生构建依赖，不声称已产出 EXE/MSI。 |
| Android | Tauri 2 移动宿主复用 Web 界面，后续接入系统文件、安全区与签名。 | 可生成独立准备目录；SDK/NDK、设备、签名及 APK/AAB 构建验收留给实际安卓发布阶段。 |
| 微信小游戏 | 相同纯规则依赖闭包、配置快照与微信存储/前后台接口；界面需要 Canvas/WebGL 实现。 | 准备包明确 `prepared / not-built / runnable:false`，不含 DOM/CSS 和运行图片；入口明确说明渲染器未实现。实际迁移、资源分包、AppID、真机及提审暂缓。 |

目标声明在 `game/targets/manifest.json`；宿主属于 `game/hosts/`，构建器属于 `tools/`。游戏本体不依赖工具、测试或 `.local/` 运行。四端使用同一规则解释器，动画始终消费状态和事件。

## 本轮验收

所有命令均以仓库根目录为工作目录。自动检查、浏览器交互、实际线上、物理手机、用户体验分别记载，不能用其中一项替代另一项。

- 自动回归：当前记录 `.local/evidence/release-regression-current.txt`；构建与图片证据见 `.local/evidence/release-assets-web-reproducibility.json`、`release-assets-integrity.json`、`release-assets-target-preparations.json`。
- 完整冒险：正式驱动 `tests/scenarios/act1-release-playthrough.mjs`，每步使用公开动作、不修改生命/香火/金钱/牌组/RNG；中途和终局保存恢复，重新独立回放并核对状态摘要。
- 浏览器：在隔离来源的真实正式包上操作；临时 QA 页面和证据只在 `.local/evidence/`，不修改正常试玩地址中的用户记录。文件导入与复制备份可用；系统 Chrome 实际下载 329,253 字节备份并通过正式校验。内置浏览器未返回下载事件属于自动化回报限制。
- 物理手机：本轮尚无 iOS/Android 实机结论；浏览器窄屏不能替代触摸、安全区、后台、弱网和内存测量。
- 用户体验：实际局时、难度、手感和最终美术效果仍由用户试玩确认。自动路线不代表这些项目通过。

首轮 Linux/Windows Node24 CI、main 分支验证和 Pages 部署均通过；公网新局、怪物详情、出牌、刷新续玩与文件恢复已实际操作，恢复前后完整状态哈希一致。线上239文件恢复及预检通过；Pages不提供的空.nojekyll仅在清单大小0、空SHA及HTTP404三项均满足时本地重建。

最终测试数量、当前构建、浏览器场景与实际 Web 地址记录在 [开发记录](DEVELOPMENT-V05.md) 的本轮条目中；旧记录保留为历史证据。

## 后续发布门槛

Web 首发需要干净 CI、HTTPS 子路径加载、保存/恢复与当前入口检查成功。后续每次发布同样执行完整流水线，遇到旧资源缺失、预算超限或保存格式变化时停止并报告，不能以不符素材降级显示。

微信阶段重启时，先实现一场真实规则战斗，再迁移地图、事件、商店、奖励、图鉴与结算；按届时官方文档核对主包/分包限制、远程素材域名、AppID/账号主体及提审材料。[微信运行环境](https://developers.weixin.qq.com/minigame/dev/guide/game-engine/cocos-laya-egret.html)、[代码包与分包](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/code-package.html)。

Windows 与 Android 真正发布前，需要各平台原生构建、签名、安装/卸载、系统文件备份、音频与后台恢复，以及对应物理设备验收。第二幕、新模式、云存档、分享与排行榜继续按后续产品需求推进。
