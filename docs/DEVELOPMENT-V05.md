# v0.5 开发与验收记录

更新：2026-10-25。用户已批准铁甲战士功能对应牌、阴债扩展，以及通用卡牌、关卡、怪物、美术分层、动画与目标拖拽的整体重整。

本文区分已实现范围、自动验证、实际浏览器操作与用户验收。下方 QA 表保留 v0.5 整合时的历史基线，不能替代目录迁移后的现场复验；用户尚未验收，浏览器验证也不等于手机真机验证。文中路径均以仓库根为基准。

## 目录迁移约定

- 游戏入口、源码、策划表及素材移至 `game/`，开发工具移至 `tools/`，正式文档仍在 `docs/`。
- 测试源码位于 `.local/tests/`，历史证据位于 `.local/evidence/`，构建输出位于 `.local/dist/`，临时文件与旧版归档位于 `.local/temp/`。整个 `.local/` 已被 Git 忽略；本地资料链接仅在保留了相应文件的工作区可用。
- 新克隆不包含本地测试与证据；`npm test` 在测试缺失时明确失败，不能报告“没有测试也通过”。内容、常规检查和构建可独立运行。
- `npm run dev` 默认从 `game/` 提供 4210 开发页；`npm run preview -- --port 4211` 提供 `.local/dist/`。受控夹具使用 `npm run dev:qa`，默认地址 `http://127.0.0.2:4212/evidence/v05-scenarios.html`；仅 QA 服务映射本地证据目录。
- 本次只是目录、工具定位与文档整理，玩法配置和用户浏览器存档规则不变。当前服务是否在线需现场确认，不沿用历史端口状态。

## 本次目录迁移的现场验证

2026-10-25，迁移后重新执行检查，配置版本仍为 `b0f18351bd641c415a41`。`npm test` 的 129 项现有测试全部通过，`npm run build` 内含的配置、源码语法与 116 张 PNG 来源检查通过，产物为 158 个文件。`npm run check:skins` 验证 16 张 UI 切片；两个卡牌裁片工具使用含 Pillow 的 Python，分别验证 9 张原像素物件裁片及 2 张独立透明物件、15 张抽象背景裁片。裁片工具已解除对归档旧卡框和旧费用图的错误依赖。

本地验收脚本 `.local/tests/layout-acceptance.mjs` 实际启动并关闭开发、预览与 QA 临时服务，每种服务逐一读取 158 个游戏文件并与构建产物比对哈希。普通开发与预览不提供 `/evidence/`；只有 QA 提供隔离夹具。仓库文件、工具、本地测试及点目录访问均返回 404；端口占用会退出，并提示当前模式的换端口命令。报告保存在 `.local/evidence/layout-migration-20261025.json`。

另将正式游戏、工具和包配置复制到不带本地测试及证据的干净目录，从其他工作目录调用构建，成功得到相同文件数；无测试时 `npm test` 入口明确失败。迁移前后的 165 个游戏文件中，164 个哈希完全一致，唯一差异是生成内容文件的工具路径注释，配置内容与玩法未变。

`.local/` 此前已有的 427 个文件仅从 Git 索引取消跟踪，磁盘文件保留；当前无被跟踪的 `.local/` 文件。目录迁移前的工具、测试和文档备份位于 `.local/temp/layout-migration-20261025/originals/`，游戏哈希清单位于同目录。没有由智能体提交、推送或发布。

文档检查入口为 `.local/tests/docs-links.check.mjs`，报告为 `.local/evidence/layout-doc-links-20261025.json`。本次验收属于自动规则、文件与 HTTP 集成验证，没有新增浏览器交互、完整冒险或真实手机验收；下方旧 QA 记录继续作为历史基线单独保留。

## 继续扩展时的约束

- 新增已有机制组合只改 JSON；新增机制先扩展通用操作、校验和场景回归，不增加某一张牌或怪物的专用分支。
- 规则先输出状态与事件，表现只消费事件；不能以动画回调决定伤害或推进回合。
- 新局使用新配置，当前局使用自身快照；不读取旧存储键，不提供旧格式迁移。
- 旧内容中仍有效的玩法和素材可进入新架构；被替换内容归档到 `.local/temp/`，不能留作运行兜底。
- 原始生成图、必要裁剪源及来源记录属于资源证据；是否活动由引用与来源链决定，不能仅按文件创建时间判断。
- 不提交、不推送、不对外发布，不修改其他游戏。用户最终验收仍以实际试玩为准。
