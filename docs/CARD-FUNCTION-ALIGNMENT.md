# 卡牌功能对齐与阴债牌设计

原始日期：2026-10-25。状态：**历史调研与设计稿，相关内容后来已在 v0.5 接入。** 本文中的差距、提案值和制作顺序记录设计阶段，不代表当前缺陷或新增任务。当前数值见 [卡牌目录](CARD-CATALOG-V05.md)，架构及验收见 [架构](ARCHITECTURE-V05.md) 与 [开发记录](DEVELOPMENT-V05.md)。路径以仓库根为基准，`.local/` 历史资料不随 Git 分发。

本稿承接用户提出的“卡牌功能对齐《杀戮尖塔1》，额外增加阴债专属牌”。下文给出当时差距、功能目标与阴债牌提案，原作规则与本作设计分开标注。实现前的源码审计快照见 [本地历史审计](../.local/evidence/card-function-audit-2026-10-25.json)，不是 v0.5 当前源码审计。

## 1. 对齐什么

建议以**一代、单人、铁甲战士、A0**作为首个角色基线。现在的80生命、5张斩魂、4张守灯、1张破煞以及战后恢复6生命，已经沿用这一框架。原作角色起始配置见 [Ironclad／アイアンクラッド](https://wikiwiki.jp/slaythespire/アイアンクラッド)。

完整目标为铁甲战士的 **75种角色牌**：3基础、20普通、36罕见、16稀有；按机械类型分为32攻击、29技能、14能力。3种基础牌不放入普通选牌奖励，因此常规角色奖励范围为72种。数量由 [一代铁甲战士牌表](https://wikiwiki.jp/slaythespire/アイアンクラッドのカード一覧)逐项统计，并与 [Ironclad Cards Reference](https://teemo.dev/game-design/slay-the-spire/systems/ironclad-cards-reference/)的计数表交叉核对。

第一幕是遭遇与路线的阶段，不等于一个只包含初级牌的独立牌池。罕见和稀有牌也可以在这一幕出现；强牌出现频率、升级和构筑条件共同决定体验。奖励规则见 [詳細仕様·卡牌奖励](https://wikiwiki.jp/slaythespire/詳細仕様)。

“功能对齐”的验收包含费用、目标、基础与升级效果、结算先后、抽弃消耗循环、持续能力和获得方式。名字、插画和叙事使用本作的地府题材。完整75种是覆盖目标，下面的制作顺序用于安排依赖，不把阶段完成描述成全部对齐。

本作继续保留跨战斗阴债、出门法器与局外解锁，它们会改变整体强度。基础牌可以逐张对齐，但含这些扩展的正式模式不能宣称与原作整体平衡完全相同。基准数值检查在不借火、没有额外出门法器影响的受控环境中进行。

## 2. 历史：实现前实际差距

审计读取静态牌表、升级后的卡面视图以及主页实际使用的新局创建入口。样本只在内存中创建，不接触浏览器的冒险记录。

| 项目 | 当前结果 | 影响 |
| --- | --- | --- |
| 牌定义 | 24种：11攻击、9术法、4状态 | 其中20种玩家牌、4种状态定义；黏液虽可打出，也不是自然奖励牌，不能把24当作24张奖励牌 |
| 已有对应基础数值 | 斩魂／打击、守灯／防御、破煞／痛击、横扫阴风／顺劈 | 这4张的费用、基础和升级数字已有对应；不代表所有隐藏交互均已验证 |
| 焚纸送魂／Immolate | 2费，当前群伤14／18，附加1张灼伤 | 原版为21／28，需要明确修正，不能标成已完全对齐 |
| 幽冥步／Shrug It Off | 当前1费，5／8护甲，抽1 | 原版为8／11格挡、抽1；旧牌并不是原版的等值替代 |
| 能力牌 | 0 | 缺少打出后持续生效的构筑核心 |
| 消耗 | 已有消耗堆、自身消耗与眩晕虚无 | 缺少主动选牌消耗、消耗触发抽牌／护甲等组合 |
| 力量与护甲 | 有状态和遗物修正 | 缺少卡牌提供成长、翻倍、保留护甲与护甲转攻击的完整链条 |
| 费用与升级 | 当前可用牌均为固定0–3费，单副本升级 | 缺少X费、战内费用变化、战内升级和无限次永久升级 |
| 牌池 | 主页初始8种；偿债成长解锁后11种；引擎默认15种 | 正式试玩不会自动用到默认15种，牌池扩充必须接到主页入口 |
| 奖励抽取 | 从当前池等概率洗牌取3 | 没有稀有度字段与稀有奖励概率变化 |
| 状态与诅咒 | 黏液、眩晕、灼伤、灼伤+；无诅咒 | 需要补伤口；诅咒应单独实现，不能与临时状态混为一类 |

焚纸送魂的原版参照见 [Immolate／焼身](https://wikiwiki.jp/slaythespire/焼身)，幽冥步参照见 [Shrug It Off／受け流し](https://wikiwiki.jp/slaythespire/受け流し)及角色牌表。旧的业火符属于自创持续伤害牌，不能因为名字含“火”就当作原版火焰吐息或燔祭。

## 3. 卡框、机械类型、稀有度分开表达

现有朱砂红／青玉绿／靛蓝／绛紫四套卡框保留，它们表达攻伐、护身、灵术、阴契这四个视觉分组。**新增能力牌不需要增加第五套家族框；阴债也不是新的机械类型。**

| 信息 | 表达方式 | 规则用途 |
| --- | --- | --- |
| 视觉分组 | 已有四套主框与对应图鉴小框 | 帮助辨认核心用途 |
| 机械类型 | 攻击／术法（Skill）／能力／状态／诅咒文字标签 | 决定地精大块头式激怒、腐化、选牌条件等交互 |
| 稀有度 | 基础／普通／罕见／稀有／特殊文字 | 决定奖励与商店抽取；不覆盖现有框色 |
| 费用 | 现有整团鬼火素材中的数字、X或“—” | 分清零费、全部剩余香火与不可打出 |

原版的五类机械类型见 [游戏系统·カード種別](https://wikiwiki.jp/slaythespire/ゲームシステム)。能力牌打出后本场离开循环，但**不进入消耗堆，也不触发消耗事件**；效果保留到战斗结束。状态通常为战斗内生成，诅咒则可保留在永久牌组中。

牌面继续使用“框＋抽象背景＋透明物件＋费用鬼火”四层。所有新图标、纹样、饰件仍只能使用正规来源或image_gen；本稿没有制作或程序绘制新美术。现有牌的主卡与图鉴继续共用背景和家族配色。

## 4. 玩家应能体验到的组合

这些是按原作功能关系整理的制作与验收目标，不是要求玩家每局强行凑齐固定套路。

| 组合方向 | 核心行动 | 第一幕中的实际用途 |
| --- | --- | --- |
| 即时输出与削弱 | 单攻、群攻、多段、易伤和虚弱 | 减少地精群数量，规划大型史莱姆分裂，安排爆发回合 |
| 力量成长 | 先获得力量，再用多段或力量倍率攻击放大 | 利用沉睡与蓄力窗口，处理长战首领 |
| 护甲转攻 | 高效防御，保留或翻倍护甲，再转成伤害 | 从单纯挨打变成可主动推进的胜利方式 |
| 消耗循环 | 清理废牌，消耗时获得护甲或抽牌 | 对付三哨卫、黏液和灼伤，同时压缩牌组 |
| 自伤换资源 | 用即时生命换香火、抽牌或成长 | 生命充足时加速；与延后支付的阴债形成不同取舍 |
| 状态利用 | 接受污染，再把状态抽牌转化成资源／群伤 | 让敌人的塞牌成为可针对和利用的机制 |

力量参照 [Inflame](https://wikiwiki.jp/slaythespire/発火)、[Spot Weakness](https://wikiwiki.jp/slaythespire/弱点発見)、[Heavy Blade](https://wikiwiki.jp/slaythespire/ヘヴィブレード)、[Limit Break](https://wikiwiki.jp/slaythespire/リミットブレイク)。护甲与消耗参照 [Barricade](https://wikiwiki.jp/slaythespire/バリケード)、[Corruption](https://wikiwiki.jp/slaythespire/堕落)、[Feel No Pain](https://wikiwiki.jp/slaythespire/無痛)、[Dark Embrace](https://wikiwiki.jp/slaythespire/闇の抱擁)。状态联动参照 [Evolve](https://wikiwiki.jp/slaythespire/進化)、[Fire Breathing](https://wikiwiki.jp/slaythespire/炎の吐息)。表内“第一幕用途”是本作设计判断。

## 6. 阴债专属牌：12种提案

以下全部是**本作设计值，尚未做平衡试玩**，不是原作卡文或已接入功能。9种沿用现有牌名与素材，3种新增功能。目标是形成“借债爆发、带债择时、实际偿债”三条交叉路线。

保留当前规则：借款通常在全局巡更+2开始到期，每点到期未还阴债扣2生命、无视护甲；普通战胜不清债，事件不推进时钟。常驻借火按钮仍最多每回合两次；阴债牌按自身费用和消耗规则结算，不假装没有借据。

下表括号内为升级值。没有列出升级变化的条款保持相同。

| 本作牌名 | 费用／类型／建议稀有度 | 基础与升级提案 | 决策作用 |
| --- | --- | --- | --- |
| 勾魂索 | 1／攻击／普通 | 造成7（10）伤害；有未还阴债时额外4（6）；由本牌击杀偿还至多2阴债 | 用负债提高集火效率，再通过击杀收尾还债 |
| 还愿符 | 1／术法／普通 | 获得4（7）护甲，偿还至多2（3）阴债 | 债到期前以防御回合完成偿还 |
| 生死签 | 2／攻击／罕见 | 造成16（21）伤害；若有将在下一次巡更开始到期的债，额外6（8）伤害 | 从“只需长期留1债”改成临近到期时的择时爆发 |
| 莲灯渡 | 1／术法／罕见 | 获得8（11）护甲，偿还至多2（3）阴债，消耗 | 高效但本场使用次数有限的安全阀 |
| 借命斩 | 0／攻击／普通 | 造成10（14）伤害，新增2阴债，巡更+2到期，消耗 | 将未来生命风险换成眼前击杀能力 |

### 6.1 三条路线如何交叉

- **借债爆发：** 借火契提供香火，配合基础群攻或X费旋风；借命斩补足击杀伤害。战斗提前结束只减少敌人行动，借据仍带入下一战。
- **带债择时：** 勾魂索利用负债，生死签在临近到期时爆发；延灯符可以救急，但也会使原本的临期增伤条件暂时不成立。
- **偿债循环：** 还愿符／销账书／摆渡钱触发司债录与引魂灯，随后用照骨镜防御；阎罗敕令把本场累计实际偿还变成终结伤害。

基础构筑不强制借债。力量、多段、护甲和消耗牌仍各自有可成立的用途；阴债带来的是额外资源与时机选择。

### 6.2 必须固定的边界

1. 偿还量取实际扣掉的本金。无债时还愿、余额不足、到期自动清除、首领胜利勾销，都不能虚增偿债、触发司债录或提高敕令伤害。
2. 司债录每回合只在首个实际偿债事件触发一次；多张能力按叠加的抽牌量结算同一个首事件。手牌达到10时停止抽取，不能借递归事件无限触发。
3. 同一笔债延期后保留借据身份与原到期时间。复制延灯符、跨战斗或刷新都不能移除“已延期”标记；没有可延期借据时明确提示不可用。
4. 到期伤害是独立的阴债来源。它不当成卡牌即时自伤去触发Rupture式力量奖励；泛化“失去生命”触发按对应原版条目另行核对。
5. 卡牌消耗不会顺便销毁借据；将带债牌消耗、移除或复制，都不能伪造偿还。
6. 本场偿债计数每场从0开始，冒险累计偿债另行保存。跨战斗的本金保留，本场能力、临时力量和临时牌则按战斗边界清理。

## 8. 制作顺序与验收

### 8.1 先补能够承载卡牌的规则

先实现能力效果区、卡牌／牌堆选择、X费、逐段攻击、消耗与抽牌触发、战内改牌和多级永久升级。保留现有uid副本身份，运行时费用和伤害由统一视图计算；手牌、详情、奖励与图鉴不各算一套。

能力离场与消耗必须分开；攻击伤害和效果伤害必须分开。不能把所有效果先汇总成一个damage再结算，否则先打再抽、多段击杀、人工制品、反伤、护甲转攻和复制都会失真。

选目标或手牌的阶段需要可恢复的等待状态。出牌前可以取消尚未承诺的选择；已经发生抽牌、伤害等效果后，不能通过关闭弹窗回滚以重选。详情的空白点击返回行为继续保留，强制选牌则另给明确的操作反馈。

### 8.2 再以完整组合接入卡牌

1. 补齐基础／普通牌与即时攻防，修正已有两张近似牌；同时接入相应抽取与升级方式。
2. 按力量、护甲、消耗、自伤、状态利用的完整链条补罕见和稀有牌。每条路线同时具备启动、运转和收尾功能，再继续扩充75种清单。
3. 接入12张阴债提案，先测借债与实际偿还，再测延期和持续能力。先确认基准规则，再对扩展进行强度调整。
4. 补齐卡面与图鉴标签，针对新增牌制作或配置有来源的前景与背景；复用素材明确记录，不宣称每张都有独立新插画。

### 8.3 验收实例
