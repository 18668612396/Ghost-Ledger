# 夜渡 · 阴债录

手机竖屏、第一人称的中式志怪卡牌游戏原型。你扮演初任鬼差，从府邸出门，在随机阴路上选择路线，观察多只鬼怪的意图，再安排出牌、借火与还债。当前 v0.5 用一套配置驱动的运行时承载卡牌、怪物、关卡和特效。

美术沿用用户参考图的浅青水彩、旧纸、暖灯笼与墨线。战斗不显示玩家小人；竖屏游戏之外为纯深色，常驻界面不另铺大底板。

## 本版可以体验什么

| 项目 | 当前内容 |
| --- | --- |
| 核心取舍 | 集火与群攻、保命与成长、借火爆发与到期索命、精简牌组与补足构筑 |
| 卡牌 | 75 种《杀戮尖塔1》铁甲战士功能对应牌，加 12 种阴债牌；另有 6 种状态、8 种诅咒，共 101 条定义 |
| 战斗 | 1–5 怪同场，25 种敌人定义；4 个弱遭遇、10 个强遭遇、3 个精英、3 个首领，另有事件专用遭遇 |
| 路线 | 第一幕 16 层、三列分支；节点数、节点类型、连线与遭遇按种子生成，部分楼层固定用途 |
| 局外 | 府邸、修行、法器选择、图鉴和夜巡档案；开放「阴路夜巡」，另两个模式保留入口 |
| 节奏 | 设计预估每局 25–40 分钟，可回府暂歇；实际难度与时长等待试玩反馈 |

通关条件是存活并击败第 16 层首领；生命归零则失败。结算后回府，再次出门。

## 仓库目录

所有开发命令从仓库根目录执行，文档中的文件路径也以仓库根为基准。

```text
Ghost-Ledger/
├─ game/              游戏本体：index.html、src/、content/、public/
├─ tools/             配置编译、开发服务、构建与素材工具
├─ docs/              正式设计、架构与开发记录
├─ .local/            Git 忽略的本地内容
│  ├─ tests/          测试源码
│  ├─ evidence/       检查记录、截图与隔离 QA 夹具
│  ├─ dist/           静态构建产物
│  └─ temp/           临时文件、旧构建和历史归档
├─ AGENTS.md          AI 协作、同模型子智能体与 Git 约定
├─ ai_context.md      当前接手说明
├─ CREDITS.md         素材来源与署名
└─ package.json       统一开发命令
```

`.local/` 不进入版本管理；新的 Git 克隆不会自带本地测试或历史证据。游戏运行与构建不依赖这些测试和证据，执行测试前需在本机恢复或添加 `.local/tests/*.test.mjs`。

## 启动

需要 **Node.js 20 或更新版本**及其附带的 npm。没有第三方运行依赖，无需安装依赖。

```powershell
cd E:\GitHub\Ghost-Ledger
npm run dev
```

启动成功后打开 [本地试玩入口](http://127.0.0.1:4210/)。保持终端运行，`Ctrl+C` 停止服务。端口被占用时使用 `npm run dev -- --port 4211`。

手机与电脑在同一局域网时，可打开 `http://电脑的局域网IP:4210/`；电脑 IP 可用 `ipconfig` 查看。实际连接取决于网络与防火墙设置，手机的 `127.0.0.1` 指向手机自己。

## 主要操作

首页点击「出门闯塔」，选择阴路夜巡、难度与出门法器，再提灯出发。有未完冒险时可「继续夜巡」。地图从下向上行进，先预览节点，再确认进入相连的下一站；战斗中打开地图只作查看。

| 操作 | 结果 |
| --- | --- |
| 单击手牌 | 打开完整卡牌详情，背景模糊 |
| 点击详情外空白、关闭或按 `Esc` | 返回打牌，不消耗卡牌或香火 |
| 单体目标牌向上拖到鬼怪身上 | 松手后对这只鬼怪出牌；只有一只怪也要拖到它身上 |
| 自身目标牌向下拖 | 底部显示蓝色鬼火引导，进入自身区域后松手使用 |
| 全场或随机敌人牌向上拖入战场 | 对配置的敌方目标使用 |
| 拖出再拖回，或松在无效区域 | 卡牌归位，不打开详情 |
| 在详情点击「打出此牌」 | 单体牌在多怪时进入选敌；自身牌和全场牌直接使用 |
| 点击图鉴、牌组或牌堆中的小卡 | 查看完整说明；小卡显示费用、类型及数量 |

手牌每页显示最多 5 张，超过时可翻页，实际手牌上限为 10。效果要求选择消耗、取回或升级的卡时，必须完成该选择才能继续结算；已经支付费用的必选流程不能用空白或 `Esc` 撤销。

键盘：`1–5` 查看当前页手牌，`Enter` 确认；选敌时 `1–5` 对应从左到右的鬼怪。`B` 借火、`R` 还愿、`E` 结束回合。详情支持 `Tab` 切换焦点；普通详情或选敌可用 `Esc` 返回。

出牌有魂火燃烧，回合末弃牌有化灰反馈；攻击命中特效由卡牌配置选择，受击鬼怪整体短暂变红。规则先结算，动画按事件播放，动画结束不会再造成一次伤害。

## 战斗与阴债

新局从 80 生命、99 冥钱和 10 张基础牌出发：5 张斩魂、4 张守灯、1 张破煞。通常每回合恢复 3 香火、抽 5 张牌。普通手牌回合末弃置，香火不保留；护甲在下回合开始清除，能力可改变这些规则。抽牌堆用尽时洗回弃牌；消耗牌本场不再循环，能力牌进入独立能力区。

| 阴债行为 | 规则 |
| --- | --- |
| 借火按钮 | 获得 1 香火、新增 2 阴债；每回合最多两次 |
| 到期 | 借据在巡更回合 +2 到期；每点未偿本金扣 2 生命，无视护甲，然后清除该借据 |
| 还愿按钮 | 花 1 香火，优先偿还最早到期的至多 2 阴债 |
| 卡牌偿债 | 只记录实际偿还量；没有欠债时不会触发还债收益 |
| 跨战斗 | 普通、精英胜战保留借据；非战斗节点不推进巡更，进入下一场战斗推进一次 |
| 延期 | 延灯符延后最早且尚未延期的一笔债；同一笔债整个冒险只能延期一次 |
| 首领胜利 | 勾销剩余阴债；勾销不算实际偿还 |

例如第 1 回合借火产生 2 债，最晚在第 2 回合结束前还清，否则第 3 回合开始损失 4 生命。12 张阴债牌分别支持负债增伤、还债护甲、偿债回能、偿债抽牌和延期，详细数值见 [卡牌目录](docs/CARD-CATALOG-V05.md)。

普通战的前 3 场来自弱遭遇池，之后进入强池，按战斗次数而非楼层计算。各只怪物独立保留生命、护甲、状态和意图，敌方按场上顺序行动。普通和精英胜战后可选牌或跳过；初始法器「归魂余烬」恢复 6 生命，精英另给法器。鬼市可以买牌、药物或删牌，歇脚可治疗、升级一个永久副本或还愿。

## 府邸、成长与存档

修行扩展选择，不永久增加基础生命或攻击。结算时累计赢得 1 场战斗可领取镇魂铃，与引魂灯互换；累计实际偿还 6 债记录还愿修行；通关后可领取进阶一重。所有阴债牌已进入第一幕奖励池，不再受局外卡牌解锁门槛限制。

当前只接受新运行格式 `version:4 / ruleset:config-v1`，**不兼容旧存档**。浏览器存储键为 `ghost-ledger.run.v4` 和 `ghost-ledger.profile.v2`。刷新或回府可继续当前格式的冒险；存档仅在同一浏览器、同一站点下有效，`localhost` 与 `127.0.0.1` 各自独立。

每个新局固定一份配置快照。修改策划表后，刷新页面并新开夜巡才会使用新配置；继续未完夜巡仍使用其快照。快照只服务同一套新运行时，不包含旧规则执行器或美术文件副本。

## 策划与开发

只修改 `game/content/*.json` 源表，不手动修改 `game/src/generated/content-data.js`。开发服务会监听表变化并编译；错误显示在终端及 `/__content/diagnostics`。开发工具位于 [tools/](tools/README.md)，目前包括编译、服务、构建和素材工具，尚无独立图形配置编辑器。

- [策划配置指南](docs/CONTENT-AUTHORING-V05.md)：新增卡牌、能力、怪物、遭遇、幕、事件和特效。
- [架构与模块边界](docs/ARCHITECTURE-V05.md)：唯一运行时、效果队列、随机数、存档与表现层。
- [美术规范](docs/ART-STANDARDS-V05.md)：四层卡面、四色家族、切片缩放、透明物件和位图特效。
- [开发与验收记录](docs/DEVELOPMENT-V05.md)：本版实现范围及分层验证状态。

```powershell
npm run content:check
npm run check
npm test
npm run build
npm run preview -- --port 4211
```

`content:check` 校验并生成配置；`check` 还检查源码语法、活动素材及来源；`test` 执行 `.local/tests/` 中的规则和场景回归，没有测试文件时明确报错。构建先使用空目录，再将旧产物归档到 `.local/temp/`，生成可独立服务的 `.local/dist/`。可选的 `npm run check:skins` 需要 Python 与 Pillow，用于像素、比例和切片检查。

普通开发服务只提供 `game/`，构建预览只提供 `.local/dist/`，均不开放本地证据。需要使用现有 QA 夹具时运行 `npm run dev:qa`，打开 [隔离 QA 入口](http://127.0.0.2:4212/evidence/v05-scenarios.html)。该服务仅监听 `127.0.0.2`，通过 `/evidence/` 提供 `.local/evidence/`；夹具可改写该来源的测试存档，避免在正常试玩来源使用。

## 当前限制

- 当前是浏览器原型，只有第一幕和一个已开放模式；没有 APK、第二幕连续闯关、云存档或跨设备同步。
- 75 张牌对齐的是铁甲战士功能与升级规则，第一幕保留原型的怪物机制；地图概率、经济、法器、事件及阴债扩展不等同于原作完整平衡。
- 全部美术有来源，卡面使用四套框、抽象背景与透明图标组合；87 张可用牌并非各有一幅独立新插图。
- 自动检查、浏览器交互、真实手机触控和用户验收分开记录。最新结果以开发记录为准，时长、难度、手感与视觉效果仍需用户试玩。
