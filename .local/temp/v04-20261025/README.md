# v0.5 替换内容归档

2026-10-25 按用户要求统一新架构，不兼容旧存档。本目录仅供追溯，不会被运行时导入，也不会进入静态构建；开发服务拒绝访问 `.local` 路径。

- `src/`：已替换的旧引擎、第一幕专用规则、卡牌表与旅程模块，以及清理前样式副本。
- `tests/`：与旧模块绑定的历史测试；当前测试在游戏根目录 `tests/`。
- `scripts/`：对应过时场景素材／旧卡框的处理脚本。
- 素材与清单：46 张不再使用的 PNG、必要的旧提示词／清单和 `asset-archive-audit.json`；活动素材及其原始来源链仍在正式资源目录。

后续构建的旧 `dist` 另存于上级 `.local/temp/dist-<时间戳>/`。不要将归档恢复为兼容分支；有价值的内容应通过当前配置表和通用规则接入。
